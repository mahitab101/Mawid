# Mawid (موعد)
Appointment booking system for clinics and service businesses, built with .NET microservices.

🚧 Work in progress: Booking service.

## Run locally
1. PostgreSQL running locally
2. Set the user secret `ConnectionStrings:BookingDb` on `Mawid.Booking.Api`
3. Run `Update-Database`, then start `Mawid.Booking.Api`
